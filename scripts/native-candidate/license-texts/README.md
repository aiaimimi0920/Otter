# Original license supplements

These are unmodified upstream license texts omitted from two published crate
archives by their `include` lists. They are not replacement license templates.

| Crate | Upstream source commit | Original paths |
| --- | --- | --- |
| `fluent-langneg 0.13.1` | `projectfluent/fluent-langneg-rs@7fdc590466ea63ca2367ac10fb1b881fe561f1a8` | `LICENSE-MIT`, `LICENSE-APACHE` |
| `intl_pluralrules 7.0.2` | `zbraniecki/pluralrules@d0715d5b7cca72e228d6e6c4de154bd30dfdd06a` | `intl_pluralrules/LICENSE-MIT`, `intl_pluralrules/LICENSE-APACHE` |

`../fluent_licenses.cjs` admits only the exact package version, registry,
declared license and crate VCS identity. It verifies each original text digest
and records its full upstream URL in the packaged inventory. Candidate source
snapshots also hash this directory. Updating a dependency requires reviewing
its original license materials again; there is no generic fallback.
