Otter 是一款免费开源的截图工具，让截图、标注、整理与分享融入日常工作。
将桌面化作工作台，连接不同的处理节点，组合功能、制作效果，让截下的画面拥有更多可能。

## 功能

- **截下你想要的画面。** 支持区域、窗口和长截图，也能随手拾取屏幕颜色。
- **把图片钉在桌面。** 让参考图随时可见，通过分组、图库和历史记录整理素材。
- **随手标注，继续编辑。** 裁剪、擦除、旋转，添加文字、箭头与图形，也能用模糊和马赛克遮挡信息。
- **让钉图实时更新。** 把窗口或局部画面变成实时钉图，持续查看内容，并与支持的源窗口交互。
- **连起节点，组合效果。** 接入 Loom 的 OCR、翻译和 Art 能力，通过连线组装自己的处理流程。
- **把画面投向其他设备。** 将图片或实时画面投射到已连接、配对的设备，方便跨屏查看与协作。

## 开始使用

- **截取钉图：** 截取桌面上任意画面，将画面钉在桌面的任意位置。
- **快速编辑：** 使用编辑栏内的工具，对钉图进行快速的标注处理。
- **连接流程：** 使用 Loom 的节点工具，进行高级工作流组装处理。
- **分享画面：** 使用推送工具，将贴图的画面推送给已连接、完成配对授权的 Otter 接收端。

| 从这里开始 | 需要做什么 |
| --- | --- |
| [下载 Otter](https://github.com/aiaimimi0920/Otter/releases) | 解压并启动 Otter App，即可开始使用。 |
| 下载 Otter + Loom | 解压并启动 Otter App 和 Loom App。在 Loom 中安装 OCR、翻译等能力包，也可按需添加常用的 MCP 工具和 Art 节点，拓展你的创作工作流。 |

1. 按 **`Ctrl+1`** 区域截图、**`Ctrl+2`** 实时截图，或 **`Ctrl+3`** 长截图。
2. 选中钉图，按 **`Ctrl+E`** 显示或隐藏编辑工具栏，**`Tab`** 展开或收起参数面板；退出编辑或选择状态后，按 **`Esc`** 删除钉图。
3. 对应 Loom 能力可用时，按 **`Ctrl+4`** 进行 OCR 识别，**`Alt+4`** 切换识别结果显示；按 **`Ctrl+5`** 翻译，**`Alt+5`** 切换翻译结果显示；按 **`Shift+1`** 打开 Art 菜单，添加新的节点。
4. 选中钉图，打开工具栏，勾选投射目标后点击“确认”。接收端选择“接收”或“自动”即可自动接收；发送端显示等待与已接收数量。两端均使用最新 Otter。

## Windows 原生主干

`main` 现在默认构建 Rust／Win32 程序，运行不依赖 WebView2。[原生开发指南](docs/guide/development.zh-CN.md)提供构建与内部打包方式。最后一个 WebView 主干保留在 `archive/webview-main`，已发布的下载不变。

原生右键的回收站、收藏夹和剪贴板子菜单使用紧凑三列卡片，支持局部滚轮滚动，每条右上角的“×”可删除对应内容。点击库卡片仍可恢复／复制。悬浮剪贴板卡片时，网格旁显示较大的文字或等比例图片预览；屏幕右侧不足时放在左侧。缩略图更新保留滚动位置。普通桌面观感仍需手测。

原生钉图右键沿用主干的保存／关闭、回收站和收藏夹布局，仅额外保留剪贴板入口。托盘右键依次为截图、实时截图、长截图、编辑已有图片、接收投射、自启动、退出，不再混入钉图库或迁移调试命令。端点条统一使用普通箭头，连线完成或取消后不会留下十字。普通桌面手势和真实跨设备收件仍需手测。

原生 `Ctrl+1` 现在直接在持续变化的桌面上选区，不再显示快捷键触发时的全屏冻结预览。拖拽松手后采集当时的选定区域，Esc／右键取消；已有钉图保持可见，Live 和长截图保留各自的选区流程。

普通区域截图现在按采集和文档准备线程的完成状态立即交付，不再等隐藏采集／导入轮询的下一次tick。松手采样和HDR保留不变；实际松手到画面出现的耗时仍受采集与首帧渲染影响。

粘贴的新钉图默认收起编辑栏，保持自由拖动；原钉图的编辑状态不变，仍可用 Ctrl+E 或 F4 手动打开新钉图的编辑栏。原图相对定位和连续粘贴的累计偏移规则不变。

复制现在使用 Windows 关闭剪贴板并补充图片格式后的最终序列号绑定内部来源，防止正常粘贴误丢失来源锚点。新增隔离 window station 的真实系统发布与读取回归；物理快捷键仍须手测。

普通启动不显示控制台、空工作区或按钮操作板，空工作区保留托盘常驻，已有钉图照常恢复。没有钉图时点击托盘，空命令宿主继续隐藏，不再显示黑色窗口。在 A 中复制后，只要仍在 A 的范围内粘贴，无论鼠标怎样移动、已有副本怎样覆盖，都从 A 的当前左上角按 20、40、60……DIP 累计堆叠。鼠标移到图外时保留复制时的相对偏移，Art 和缩略图的扁平副本同样适用。Shift 拖出默认使用 `{label}_{shortId}_{date}_{time}.png`，时间精确到百分之一秒，同名不覆盖。物理剪贴板／拖动和普通桌面观感仍须手测。

Tab 左右行、行内控件、连续底板和底部节点抽屉跟随各自钉图的层序和置顶状态，不再放到工作区最低的钉图下方。底部三角展开／收起保持水平位置不变。端点内容（包括 Tab、F2）与编辑工具栏首个按钮打开的左侧“钉图设置”双向互斥，参数草稿保留。黄色三角打开的底部抽屉独立，可与上述任一界面同时存在。行间隙保持穿透，字段获取焦点不重排钉图。普通桌面观感仍须手测。

原生 `Shift+1` Art 菜单采用居中的 250×300 DIP 紧凑搜索布局，支持清空、关闭与单击选择；保留原模态、IME 与授权流程，不代表非模态行为完全对齐。底部收起标记裁掉三角外的矩形，Tab 更新保留完整控件帧。空闲 Pan 或静默模式下可 Shift 拖出新生成的 PNG 到文件夹；允许移动的只有导出副本，不是原图片。物理拖动和普通桌面观感仍需手测。

尚未公开发布的 Windows 原生开发版新增`F6`端口导航、`Ctrl+Enter`键盘连线，以及公共Art参数端口的`F2`进入对应附着参数行的原生控件。这是开发分支操作，不表示下载页公开版已有这些键位，也不表示普通桌面验收已完成。具体操作及验证边界见[当前原生对等记录](docs/development/WINDOWS_NATIVE_PARITY.md)。

原生编辑栏第二个按钮现为选择开关：`Ctrl+E` 打开编辑栏时默认开启，再点一次（或按 `Q`）进入静默，不再点选已有标注；新建标注完成后仍保留当前选择，可直接调整。已移除选择／移动／旋转／缩放下拉模式，所选标注的操作柄和修饰键手势保留，旋转圆点与缩放方块跟随拖动预览。普通桌面观感仍须手测。

原生编辑栏的选择模式下，`Ctrl+Alt+滚轮`围绕组中心缩放已选标注，额外按住`Shift`改为围绕各自中心缩放；不会改变钉图窗口大小或透明度。手测步骤见[功能回归矩阵](docs/FEATURES.md)。

原生线段分组只保留直线和贝塞尔曲线；箭头仍作为线条属性提供，不再提供重复的独立箭头／折线入口及其 A/U 工具快捷键。主编辑栏与二级属性栏的绘制优化仍须普通桌面手测验收。

原生分支还会读取可信 Loom 扩展声明的快捷键，包括对应已安装能力声明的 OCR／翻译执行与结果显隐；原生文字输入控件保留自己的编辑按键。物理键盘和真实模型验收不由源码回归替代。

原生分支的官方 OCR／翻译覆盖文字支持单块点击复制、同块拖选和 Ctrl+C，不会带动钉图移动；空白处和绘制工具仍保留原操作。验证边界见[功能回归矩阵](docs/FEATURES.md)。

官方 OCR 数据类型仍有效、renderer 暂缺时可继续显示已保存的覆盖文字；扩展数据不可用时显示有界且不抢输入的占位。能力离线或撤权后不会继续绘制旧附件场景。

原生扩展操作反馈在钉图上保留最新八条通知，支持通知栈和长通知内部滚动、五秒自动关闭，并随钉图移动而不抢焦点；通知区域的滚轮不改变钉图缩放或透明度。普通桌面观感仍须独立验收。

与主干一致，活跃开发模式扩展可以显示已保存视图并保留通知；显示资格不授予扩展命令、快捷键或附件写入权限，这些操作仍保留原有 trusted 执行边界。

原生钉图设置补入主干的“原文／译文”全文复制按钮。已隐藏的缓存结果仍可复制，不执行模型；过期译文不可用。全文不会被静默截断，点击的按钮短暂显示成功或失败反馈。

原生 Tab 端口行展开后也显示原先隐藏的端口，可用主干眼睛图标直接切换收起时的显隐；不会删除连线。Tab 总展开后，普通图片及公共 Art 参数的真实控件附着在对应胶囊行内；显式输入保持固定，下方参数区独立滚动，滚动保留文本草稿和 HWND，类型选项及批量提交复用原事务。局部展开、总 Tab 和 F2 共用行内 owner，多行可同时独立展开；本地 Art 独立表单及右侧辅助区仍在迁移。

原生 Ctrl+E 编辑栏也会显示可信扩展贡献的文字按钮及分组命令列表。目录或图片来源变化后，旧点击不再有效；执行仍沿既有命令授权链。Art VIEW 视图选择和剩余 Tab／连接 UI 仍在迁移。

原生普通画笔的荧光开关保留当前画笔工具、不透明度和平滑度字段。荧光笔迹沿用 35% 底色并乘以画笔不透明度，保留画笔平滑、撤销／重做与会话恢复；不再提供重复的独立荧光笔入口和 H 工具命令，已有荧光笔迹保持原渲染。

原生文档钉图在明确点击节点或 Tab 展开后提供底部附着设置栏，沿用原图标，控制收起端点显隐、下游通知、贴图编辑继承及 Art 自动／手动执行。它与所属钉图在同一移动批次及层序组内跟随，可与端点内容同时展开，不是左侧“钉图设置”属性栏。已有参数草稿先经原事务提交，再修改设置或执行。业务设置随会话保存，抽屉展开态不保存。完整节点多选、独立 Live 设置、Art VIEW 及连接／投射 UI 仍在迁移；普通桌面观感须独立验收。

原生 Tab 端点行隐藏后保留正常大小钉图中的原行空位；Tab 总展开变化会同步各行，此后每个锚点仍可独立收起／展开。连续展开行采用主干整组深色底板，行间空隙不增加点击区域；输出眼睛和名称沿用主干内容槽位。只聚焦端点或点击文字不会展开，连线手势从锚点开始并落到锚点。现有字段编辑器仍属过渡实现，不代表完整主干行内参数控件已迁移；普通桌面观感仍须单独手测。

原生分支的公共 Art 多候选结果现附着在 Tab 右侧输出端口下方，使用紧凑卡片和独立局部滚动，选择复用原候选／参数执行事务。真实多结果 Loom 和普通桌面观感仍须独立验收；Live 辅助设置及本地 Art 表单继续迁移。

原生钉图设置提供连接／断开、当前 Loom 账号、设备／设备组／用户多选和四项紧凑接收策略。二维码与链接面板位于钉图内，可切换局域网／公网，统一通过当前已授权的 Loom；选择 PNG 或粘贴链接只在本地解析，点击导入才接受并新增关联钉图，保存后显示。接收图提供来源和解绑入口。只支持当前 v2 客户端。两个不同合成账号、两个真实 Loom 的 Application 联合流程已通过 PNG 更新、重开和解绑；普通桌面、物理跨机与真实公网验收仍单列。详见[当前分享范围](docs/features/QR_PROJECTION.md)。
