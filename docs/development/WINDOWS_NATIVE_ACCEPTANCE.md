## P2：普通双产品业务、资源、长稳与退出

当前执行顺序以用户最新决定为准：先验证非资源的功能生命周期及普通退出，以下资源场景/期限/预算合同保留到后续全盘排查时使用，不是本轮立即执行或已通过的项目。功能崩溃、挂起、取消、保存和回收不因资源延期而忽略。

普通Otter退出现由用户在新profile的v545普通测试窗口完成正式菜单操作，反馈“已退出”；开发侧无UI输入地观测root exitCode0、4进程自然归零、监听空、保存图片及身份保留，无Job强制兜底。普通静态工作区退出子项关闭，Loom已过结果复用，不重测。前次忘记操作与更早超时原回执保留，不当作当前失败；本次不覆盖活动Art/Live、未保存选择或资源长稳。

使用普通 Otter、普通 Loom 壳、daemon、WebView2 和必要 worker/输出进程整树，不能只测主 EXE。
按原合同覆盖空托盘、单张4K、十张钉图、复杂标注/连续擦除、长截图、单/多路Live、投送、
关闭全部内容后回落和循环开关；分别标出冷启动/预热、空闲、活跃、停止回落及退出阶段。

执行前在回执中冻结场景顺序、输入/安装与启用数量、观测期限、采样间隔、循环次数和判定条件；
优先复用现有运行器，不无限延长，不以重复运行等待一个好结果。普通业务和资源期限未冻结时不启动。
数值预算仍须受控基线后确定：已有约359MiB不是合格线，未有预算不能宣布达标。

CPU 同时报单核口径 `100 × ΣΔCPU秒 / Δ墙钟秒`，整机口径再除以逻辑处理器数。
Private bytes、private working set、working set 分列，线程/句柄、GPU 专用/共享归属分列，
共享页及共享 GPU 不直接相加当物理占用；进程 I/O 字节不得冒充物理磁盘写入。
记录实际磁盘指标的采集方式、覆盖范围与开销；GPU/物理磁盘不可取得即如实标未验。

停止后检查任务/内存/句柄是否回落，退出后核整树及监听。普通关闭、壳 kill/wait 回收 daemon、
Job 兜底与异常结束分报；Loom 已过的是普通壳正常关闭及整树回收，不是 daemon 自愿退出。
600秒私有 desktop 空闲或 WGC→Loom 夹具链不代本组普通业务/长稳，当前 P2 仍未通过。
