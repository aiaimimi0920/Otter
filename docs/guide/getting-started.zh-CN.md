# Otter 使用教程

[English](getting-started.md) · [文档中心](../README.md)

## 准备与启动

- Windows 10 或 11。将当前内部 ZIP 完整解压，运行 `otter-native.exe`，并保留同目录的 `otter_live_hover_hook.dll`。内部包未签名，不是公开发行版或安装包；历史公开下载按各自发行说明使用。
- 截图、钉图、标注可独立使用。OCR、翻译和 Art 需要当前 Loom、对应能力包及授权。
- 默认工作区和设置位于 `%LOCALAPPDATA%/OtterNative`，与历史版目录独立。测试可用 `OTTER_NATIVE_PROFILE_DIR` 指定独立的绝对路径；不要覆盖使用中的目录或转移设备凭据。

## 1. 截取并钉在桌面

1. 启动 Otter，按 **`Ctrl+1`**，框选要截取的区域。
2. 画面生成钉图后，可将其移动到桌面需要的位置，作为参考或继续编辑。
3. **`Ctrl+2`** 用于实时截图，**`Ctrl+3`** 用于长截图；实时截图的源程序兼容性和资源限制见[实时截图说明](../features/LIVE_CAPTURE.md)。

不支持在 UAC 安全桌面内截图或覆盖钉图。实时截图不保证任意程序的后台输入或固定帧率，详见[安全边界](../security/SECURITY_BOUNDARIES.md)。

## 2. 编辑与标注

1. 选中钉图，按 **`Ctrl+E`** 显示或隐藏编辑工具栏。
2. 使用文字、箭头、形状、画笔、模糊等工具处理画面；按 **`Ctrl+Z`** 撤销，**`Ctrl+Y`** 重做。
3. 钉图具有焦点时，按 **`Tab`** 打开参数面板。进入面板后，Tab 在控件间导航，
   **`Esc`** 取消已编辑的输入值或退出面板。
4. **`Esc`** 优先取消当前手势、选择或弹窗；钉图空闲时才会关闭钉图，不是删除源文件。删除选中的标注使用 **`Delete`**。
5. 按 **`Ctrl+S`** 保存所选图像。在浏览／平移状态下，按住 **`Shift`** 可将 PNG 副本拖出到资源管理器；编辑工具可能将 Shift 用于自己的操作。

进一步阅读：[笔迹与曲线](../features/BEZIER_EDITING.md) · [功能与快捷键](../FEATURES.md)。

## 3. 使用 OCR、翻译与 Art 节点

先启动 Loom，安装并启用所需能力包，完成 Otter 与 Loom 的连接及授权。连接、审批与重新连接的操作见[全局 Loom 连接](../features/LOOM_CONNECTION.md)。

选中图片钉图，且能力目录提供以下绑定时可用；实际快捷键及可执行动作以已安装目录和授权为准：

| 快捷键 | 操作 |
| --- | --- |
| **`Ctrl+4`** | 使用可用的 OCR 能力重新识别；复制完整结果还需剪贴板权限。 |
| **`Alt+4`** | 切换 OCR 结果显示；没有结果时先识别并显示。 |
| **`Ctrl+5`** | 翻译已有 OCR 内容；没有 OCR 时先识别。 |
| **`Alt+5`** | 切换翻译结果显示；首次使用时生成所需结果。 |

按 **`Shift+1`** 打开 Art 菜单，再选择可用能力添加节点。
菜单快捷键由 Otter 内置，候选内容仍取决于能力目录与授权。

在 Otter 的节点工作区中连接节点、组合处理流程；Loom 提供已安装并授权的能力。节点及参数以实际可用能力为准。OCR 和翻译的显示控件互斥，切换已有结果不会重复请求模型。

恢复本次会话中已关闭的 Surface 时，在 Loom 菜单查询已关闭的 Surface，再明确确认恢复候选。
详见 [Surface 恢复边界](../development/SURFACE.md)；这不表示跨进程或跨版本自动恢复。

## 4. 将钉图投射到另一台设备

这里的设备指支持现有投射协议、完成所需连接与授权的 Otter 接收端，不表示任意客户端或所有平台都兼容。先从两台运行 Otter 的 Windows 电脑、同一 Loom 的已配对设备开始：

1. 两端连接同一 Loom，并完成设备配对及批准。接收端需启用接收；“接收”与“自动”会自动接受符合授权的新投送；“暂停”与“拒绝”不会。
2. 发送端选中钉图，按 **`Ctrl+E`** 打开工具栏，从“钉图设置 → 投射”进入面板。
3. 打开目标设备或设备组列表，勾选可用目标后点“确认”。发送端收到接收回执后才标记成功；请在接收端核对实际钉图。
4. 关联建立后，发送端后续编辑会持续同步。取消勾选并确认可停止投射；关闭面板不会自动停止已有同步。

也可使用二维码或链接邀请；接收端从托盘“接收投射”或钉图内的导入入口接收。邀请有效期、跨 Loom 互信、接收策略与双向编辑限制见[图片投射完整说明](../features/QR_PROJECTION.md)。

## 遇到问题

- OCR、翻译或 Art 不可用：检查 Loom 连接与授权，以及对应能力包是否安装、启用。
- 找不到接收设备：检查两端连接、配对审批和接收策略；“已连接”不代表所有远程业务都已开放。
- 快捷键行为不同：确认当前是否选中钉图、标注或输入框，以及是否仍处于编辑状态；以当前快捷键配置为准。
- 反馈前搜索[已有 Issues](https://github.com/aiaimimi0920/Otter/issues)，按[社区参与方式](contributing.zh-CN.md)提供版本、复现步骤和经过脱敏的截图。不要上传密钥、令牌或私人画面。
