# 能力详解

[English](capabilities.md) · [文档中心](../README.md)

- **截图**：`Ctrl+1` 区域/窗口截图，`Ctrl+2` 生成[实时贴图](../features/LIVE_CAPTURE.md)，
  `Ctrl+3` 长截图。多张实时贴图按资源预算接纳，不会为了打开新贴图自动删除已有贴图。
- **贴图和画布**：`Ctrl+E` 打开编辑栏，支持裁剪、标注、笔刷、曲线、撤销、工作区保存、
  回收站与参考图库。按住 Shift 可将图片拖出到资源管理器。详见[快捷键与功能](../FEATURES.md)。
- **Loom 与 Art**：[连接 Loom](../features/LOOM_CONNECTION.md)后可使用已安装、启用且授权的
  扩展。OCR、翻译与扫码来源于相应能力包；没有 Loom 时，本地截图与编辑仍可使用。
- **投射**：在钉图的投射面板选择设备/设备组，或通过[二维码和链接](../features/QR_PROJECTION.md)
  分享。默认策略显示为「接收」；「接收」和「自动」均可接受符合授权的投送，不需要二次审批。
  「拒绝」与暂停各自控制新投送参与，不替代 Loom 的设备授权。配置损坏时拒绝新投送。
- **瓷砖终端**：`--tile` 为 Loom 管理的[墙面输出](../features/TILE_TERMINAL.md)，
  与普通投射贴图、LiveRelay 观看端不同，不代表物理墙面已经完成联合验收。

受保护内容、UAC 安全桌面以及跨用户或越权输入不在支持范围内。
